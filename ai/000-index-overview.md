# What learning pathways do I follow next?


## Possible area: Become more expert at getting the most out of coding assistants

Explore whether and how to become more productive at building software

Options

- Experiment with how to set up a codebase for maximum AI utility
- Read the docs of Github Copilot to learn it's features and understand how it works
- Experiment with copilot competitors like windsurf and cursor
- Try out the CLI tool agents and see where/how they can help me
- Zoom out on my/our software dev workflow and consider how/if to change it to make AI more useful
	- Figure out how to evaluate whether that actually helps or not
- Read more stories from devs using AI tools for ideas


## Possible Area: Understanding the LLM products

- OpenAPI/Claude APIs, how to use, libs for using etc., limitations, lessons learned, costs
- How models are served and the ops constraints that impact costs e.g. vLLM stuff
- Learn about Claude skills

## Possible area: Understand the underlying tech of LLMs

- Books, courses, play with small models, try training my own etc.
- Use pytorch etc. for training
- Where are we on continual learning?
- What are the frontiers that model providers are working on?

## Possible area: AI that isn't LLMs

- What's going on here? What can I learn?

## Explore new products built on LLMs

- What new features/products are around? Are they worth it? Do they matter? Do I care?
- e.g. OpenAI web browser - good idea or bad?

## Explore the work and society changes AI will/might bring

- What will happen to the open web? How do we get ready? How do we help clients get ready?
